# Scaify Wireframe Spec

## 1. Project Overview

Product: `Scaify`  
Target: `Tax MVP demo`  
Primary platform: `Desktop`  
Canvas: `1440 x 1024`

## 2. Layout System

- Grid: `12 columns`
- Margin: `80`
- Gutter: `24`
- Sidebar width: `240`
- Main content width: `1120`
- Spacing scale: `8 / 16 / 24 / 32`
- Card radius: `16`
- Primary CTA position: `top-right of content area`

## 3. Frame Set

### Frame 01 - Upload Default

Frame ID: `01_Upload_Default`

Purpose:
- Upload CSV settlement and invoice images.
- Establish the initial entry state.

Layout:
- `Sidebar`
- `Topbar`
- `Page Header`
- `Upload Zone`
- `File Requirement Card`
- `Recent Uploads Card`

Dimensions:
- Sidebar: `240 x full height`
- Topbar: `1120 x 72`
- Page Header: `1120 x 88`
- Upload Zone: `720 x 360`
- File Requirement Card: `360 x 172`
- Recent Uploads Card: `360 x 172`

Content:
- Page Header:
  - Title: `Tải dữ liệu lên`
  - Subtitle: `Tải file CSV settlement và ảnh hóa đơn để hệ thống xử lý`
- Upload Zone:
  - Large upload icon
  - Hint text: `Kéo thả file vào đây`
  - Secondary buttons: `Chọn CSV`, `Chọn ảnh hóa đơn`
  - Supported formats: `CSV, JPG, PNG, PDF`
- File Requirement Card:
  - `1 file CSV`
  - `1 hoặc nhiều ảnh`
  - `Ngày đúng kỳ`
  - `Dung lượng hợp lệ`
- Recent Uploads Card:
  - `2 dòng upload gần nhất`
  - Status examples: `Processed`, `Draft`

States:
- Empty upload state
- Ready-to-upload state

Frame ID: `03_Processing_Review`

- `Sidebar`
- `Topbar`
- `Header`
- `CSV Preview`
- `Document Preview`

- CSV Preview: `360 x 640`
- Document Preview: `680 x 640`
- Extracted Fields Panel: `416 x 640`
- Reconciliation Summary: `1120 x 120`
- Process Timeline: `1120 x 120`

Content:
- Header:
  - Title: `Đang xử lý dữ liệu`
  - Badge: `OCR + Parse CSV`
- CSV Preview:
  - Settlement summary table
  - Highlight fields: `revenue_raw`, `platform_fees`, `refunds`
- Document Preview:
  - Large invoice image

- Extracted Fields Panel:

## 4. Component Notes

- KPI cards should reuse one base component with variant labels.
- Alert cards should reuse one severity component: `low`, `medium`, `high`.
- Tax summary card should support both:
  - summary mode
  - breakdown mode
- Correction drawer should be reusable for OCR amount and invoice date.

## 5. Interaction Notes

- `Upload -> Process`
- `Alert -> Explain Tax`
- `Correction -> Recalculate`
- `Success -> Refresh alerts and KPI`

## 6. Visual Priority

1. The dashboard KPI row should be the first visual anchor.
2. The alert banner should be the second visual anchor.
3. The correction drawer should clearly dominate the right side when open.
4. The OCR / CSV reconciliation should be visible before the user reaches the dashboard.
